PEAK PACT — Alpha 1.8.x (North Pact Games)
==========================================

УСТАНОВКА
1. Распакуй ZIP куда угодно (например D:\Games\PeakPact)
2. Запусти Install-PeakPact.bat — появится ярлык на рабочем столе
3. Или двойной клик PeakPact.vbs / Start-PeakPact.bat

ЗАПУСК БЕЗ NODE.JS
Игра открывается в окне браузера (--app), без терминала.

ДОНАТ (Payhip)
- Магазин → донатный скин → «Купить» → «Оплатить на Payhip»
- После оплаты введи код активации (например NP-KISH-001)
- Настройка ссылок: см. DONATE.txt и PAYMENT_CONFIG в peak-pact.html

ОНЛАЙН
- Вкладка Онлайн: IP:порт сервера (или свой server.js)

ФАЙЛЫ
- peak-pact.html — сама игра
- game/ — копия для лаунчера
- DONATE.txt — инструкция по Payhip
